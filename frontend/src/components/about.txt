Developed a full-stack web application that streamlines the entire health insurance lifecycle from policy application to administrative management. The system provides an intuitive interface for users to explore, purchase, and manage health insurance plans while offering administrators powerful tools for policy oversight and data management.

Key Features:
Multi-step insurance application form with real-time validation
Secure user authentication and profile management using Firebase Auth
Mobile-responsive design with dark/light mode toggle
Comprehensive admin dashboard for policy management and data analytics
Family coverage management with relationship and age validation
Multiple dummy payment gateway integrations (UPI, Cards, Net Banking, EMI) 
PDF generation for policy documents and application summaries
Gender-specific benefit restrictions (maternity coverage for female applicants only)
Auto-population of user data from authentication profile
Toast notifications for real-time feedback on user actions

Technical Stack: 
Frontend: React.js with React Router, Tailwind CSS, Context API for state management
Backend: Node.js with Express.js REST API, modular controller architecture
Database: PostgreSQL with schema-based organization, connection pooling
Authentication: Firebase Authentication with role-based access control
Deployment: Render cloud platform with environment-specific configurations

Data Management: 
Five normalized database tables handling personal info, addresses, coverage details, family members, and health information
Transaction-based operations ensuring data consistency
Admin panel with CRUD operations, search functionality, and bulk data management
Secure API endpoints with input validation and SQL injection prevention

This project demonstrates proficiency in full-stack development, database design, user experience optimization, and modern web development best practices while solving real-world insurance management challenges.
